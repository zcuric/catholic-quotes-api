For people building with the archive

A small, cited Catholic text API.

Read-only, no authentication required. Use the endpoints below to search English-language quotations and cited primary texts, while retaining the source and licence metadata attached to each record.

Getting started

Every route is available below the same domain as this page. The API returns compact UTF-8 JSON and permits cross-origin GET requests. There are no keys, accounts, or write operations.

Use /api/health first to confirm that a deployment is available and to see the current record counts.

GET /api/health

{
  "ok": true,
  "language": "en",
  "record_count": 6203,
  "datasets": { "catena": 4858, "wikiquote": 1345 },
  "croatian_sources_included": false
}

Endpoints

The archive separates short attributed quotations from cited passages in primary Catholic texts. Attributed quotations are the default response. Catena responses are concise, complete-sentence excerpts with the canonical citation and original source link retained.

GET/api/health

Availability, language, dataset counts, and the Croatian-source exclusion flag.

GET/api/quotes

Search and paginate records. This is the primary endpoint for applications.

GET/api/random

Return one record, optionally limited to a dataset.

GET/api/sources

Dataset labels, descriptions, and licence notes.

GET/api/saints

Wikiquote authors with the number of available quotations.

GET/api/docs

The concise machine-readable description of these endpoints.

Query parameters

Use these parameters with /api/quotes. The search matches the quotation text, author, collection, and citation. Multiple search words are combined, so a narrower query returns a narrower result set.

source
Optional. wikiquote (default) for attributed quotations; use catena for longer cited primary texts, or all for both.
q
Optional. A search phrase; up to eight terms of two or more characters are used.
author
Optional. Case-insensitive partial author match.
collection
Optional. Case-insensitive partial collection match, useful for the Catena dataset.
full
Optional. Catena is concise by default. Set full=1, full=true, or full=yes to return the complete cited source unit.
limit
Optional. Records per page; from 1 to 100, default 25.
offset
Optional. Zero-based result offset, default 0.

Examples

GET /api/quotes?source=wikiquote&author=Thomas%20Aquinas&limit=5
GET /api/quotes?q=mercy&collection=Roman%20Catechism
GET /api/random?source=catena
GET /api/quotes?source=catena&full=1&limit=1

Record format

Search responses include pagination fields and an items array. Some descriptive fields can be null when a source does not provide them.

{
  "source": "wikiquote",
  "language": "en",
  "count": 446,
  "limit": 25,
  "offset": 0,
  "items": [{
    "id": "…",
    "dataset": "wikiquote | catena",
    "text": "The quotation or cited passage.",
    "author": "…",
    "collection": "…",
    "citation": "…",
    "title": "…",
    "work": "…",
    "source": { "domain": "…", "url": "…" },
    "license_note": "…",
    "quote_type": "author_quote | canonical_text",
    "is_excerpt": false
  }]
}

canonical_text is a cited excerpt from a primary work. author_quote is an attributed quotation gathered from the Wikiquote source set. is_excerpt is true when a long Catena source unit has been reduced to a complete-sentence excerpt; request full=1 to obtain the original unit.

Sources & licences

The current snapshot contains English Wikiquote records and Catena units from the Summa Theologiae, Catena Aurea, and Roman Catechism. It deliberately excludes Croatian JSON, HKM, and Compendium data.

Attribution and licensing travel with each record, but you should still verify the underlying work and edition before republishing a quotation, especially translations and material obtained through Wikiquote.

# Catholic Quotes API

A small, read-only API for finding English-language Catholic quotations and
cited primary texts. Each response keeps the attribution, source URL, and
licence note supplied by its source.

The public archive is intentionally separate from the Croatian scraper project:
it contains no Croatian JSON, HKM material, or Compendium database content.

## What is in the snapshot

The checked-in, read-only SQLite database currently contains:

- 1,345 English attributed quotations from Catholic-author Wikiquote pages;
- 4,858 longer, canonically cited Catena units from the *Summa Theologiae*,
  *Catena Aurea*, and Roman Catechism.

Attributed quotations are the default in both the website and the API. Catena
records are deliberately opt-in because they are longer excerpts intended for
reading in context.

## Use the API

No API key or account is required. The API accepts cross-origin `GET` requests
and has no write operations.

| Route | Purpose |
| --- | --- |
| [`/docs`](/docs) | Human-readable documentation |
| [`/api/health`](/api/health) | Availability and record counts |
| [`/api/docs`](/api/docs) | Compact JSON API description |
| [`/api/quotes`](/api/quotes) | Search and paginate records |
| [`/api/random`](/api/random) | One randomly selected record |
| [`/api/sources`](/api/sources) | Dataset and licence metadata |
| [`/api/saints`](/api/saints) | Available Wikiquote authors |

The default is `source=wikiquote`. Select the longer source explicitly with
`source=catena`; use `source=all` only when an application genuinely needs
both collections.

```text
GET /api/quotes?q=mercy&limit=10
GET /api/quotes?source=wikiquote&author=Thomas%20Aquinas
GET /api/quotes?source=catena&collection=Roman%20Catechism&limit=5
GET /api/random?source=wikiquote
```

See [`/docs`](/docs) for query parameters, response shape, and examples.

## Run locally

The project has no third-party Python dependencies.

```bash
git clone https://github.com/zcuric/catholic-quotes-api.git
cd catholic-quotes-api
python3 local_server.py
```

Then open <http://127.0.0.1:8787>. Do not open `index.html` directly: a
`file://` page has no API origin.

## Deploy on Vercel

Import this repository as a Vercel project. Leave the repository root as the
root directory, choose the **Other** framework preset, and leave the build and
output settings empty. `vercel.json` includes the SQLite snapshot with the
Python function and routes `/docs` to the HTML documentation page.

Every push to `main` can trigger a new deployment.

## Data, attribution, and licensing

This repository’s **source code** is released under the [MIT License](LICENSE).
The text data in `data/international.sqlite3` is not relicensed as MIT.

Every returned record includes `source.url` and `license_note`. Wikiquote
material is generally CC BY-SA/GFDL and individual quotations can have their
own copyright status. Catena units are marked public domain by their source,
but editions and translations still need care. Verify the underlying source,
edition, and rights before redistributing any record.

## Updating the snapshot

The database snapshot is generated by `build_international_sqlite.py` in the
separate source-data project. Regenerate it there, replace
`data/international.sqlite3` here, review the counts and source metadata, then
commit the new snapshot. Deployment never depends on downloading data at build
time.
